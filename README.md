# Trey Durden — Thermal Applications Engineering & HVAC Specialist

Modern, responsive multipage website featuring an interactive climate studio stage, custom bento grid architecture, and service accordion modules.

## Project Structure

```text
├── index.html        # Home / Climate Studio Hero & Practice Overview
├── products.html     # Hardware Studio (Primary Stage + 4 Thumbnails + Placeholders)
├── services.html     # Thermal & HVAC Engineering Services (7 Interactive Accordions)
├── about.html        # Trey Durden Engineering Heritage & Certifications
├── contact.html      # Project Intake & Direct Engineering Consultation Form
├── css/
│   └── style.css     # Clean Vanilla CSS3 Architecture (Tokens, Layout, & Themes)
├── js/
│   └── main.js       # Pure Vanilla JavaScript (Climate Switcher, Accordions, Gallery)
└── images/           # High-resolution SVGs and optimized equipment imagery
```

## Features

- **Interactive Climate Switcher**: Real-time dual mode (Heating & Cooling) load balancing.
- **Hardware Blueprint Stage**: 4-thumbnail interactive equipment switcher with smooth transitions.
- **Dynamic Accordion Architecture**: Deep-linkable accordion breakdowns with filter pills.
- **Zero External Dependencies**: Built with 100% pure HTML5, CSS3, and modern Vanilla JavaScript for maximum performance and instant load times.
- **Responsive & Mobile Ready**: Full-screen modal navigation overlay with custom shortcut branding.

## Deployment

Simply deploy all files to any standard web server (Apache, Nginx, cPanel, Vercel, Netlify, or AWS S3). No build step required.
